## Social preview

Use a real product composition rather than a generic AI/audio stock image.

Recommended 1280×640 composition:

- dark OxShift Studio background based on the shipped UI palette;
- large `OxShift` wordmark and concise line: **Voice. Sound. Local.**;
- one real Studio screenshot crop showing voice controls/effects chain;
- one smaller Soundboard crop showing waveform/trim controls;
- small platform chips: **Windows · Linux · Local-first**;
- no unsupported claims such as “zero latency”, “AI clone any voice”, or “native virtual driver”.

Before uploading the social preview, capture screenshots from the actual Alpha build at 100% UI scaling so the preview does not advertise UI that is not shipped.
